# 2026-07-31 设置窗口简体中文化变更日志

## 1. 修改概述

为 Zed 的设置窗口接入 English / 简体中文显示语言切换。此前语言切换只覆盖应用菜单；本次将设置窗口的标题栏、导航、分组标题、设置项标题、常规页说明、常用按钮、提示文本、无障碍标签和中文搜索索引一并接入。

## 2. 需求来源

### 用户反馈

切换为简体中文后，设置弹框中的大部分内容仍显示 English。

### 目标结果

当 `ui_language` 为 `simplified_chinese` 时，设置窗口的主要可见文本显示为简体中文；切换语言后，已打开的设置窗口无需重启即可刷新。

## 4. 核心实现说明

### 修改前

设置页面中的页面名、分组名、设置项标题、说明、搜索占位符与操作按钮直接使用英文字符串。即使 `ui_language` 已切换为 `simplified_chinese`，设置窗口也不会重渲染这些文本。

### 修改后

`settings_ui::localized` 根据 `UiLanguageSetting` 在渲染时返回中文或英文文本。稳定的英文字符串继续作为页面数据、元素 ID、深链接和遥测字段，避免影响设置路径及现有行为；仅展示文本与无障碍文本本地化。

语言变化由 `SettingsStore` 观察器检测。变化时会更新窗口标题与搜索占位符、重新测量列表并重建搜索索引，随后通知窗口重新渲染。

### 选择原因

设置页面已有大量稳定英文键值和深链接。渲染时翻译能够在不改变设置文件、JSON 路径或动作名称的前提下完成即时切换，并保留未覆盖文本的英文回退。

### 未采用方案

没有把设置页数据源改写为中文字符串，也未变更 `settings.json` 的枚举值或 JSON 路径；这会破坏深链接、搜索索引和兼容性。

## 5. 关键函数说明

### `localized`

- 作用：将设置窗口使用的稳定英文文本转换为当前显示语言。
- 输入：英文静态文本及应用上下文。
- 输出：英文或简体中文文本。
- 调用关系：设置项布局、导航、标题栏、搜索、按钮、提示和无障碍标签均通过该函数渲染。
- 注意事项：未知文本返回原始英文，避免出现空白或错误文案。

### `localized_shared`

- 作用：翻译以 `SharedString` 保存的子页面和操作链接文本。
- 输入：动态共享字符串及应用上下文。
- 输出：本地化后的共享字符串。
- 调用关系：用于子页面链接、操作链接和面包屑。
- 注意事项：保留原字符串作为元素 ID 与导航标识。

### `SettingsWindow` 的 `SettingsStore` 观察器

- 作用：在 `ui_language` 改变时刷新已打开的设置窗口。
- 输入：新的全局设置快照。
- 输出：更新窗口标题、搜索占位符、列表测量和搜索索引。
- 调用关系：设置语言下拉框写入配置后触发设置存储更新，再由观察器刷新界面。
- 注意事项：仅在语言实际变化时重建搜索索引，避免普通设置修改产生额外开销。

## 6. 配置变更

没有新增配置字段；继续使用已有的：

```json
{
  "ui_language": "simplified_chinese"
}
```

支持值仍为 `english` 和 `simplified_chinese`。旧配置不含此字段时保持 English 默认值。

## 7. 影响范围分析

### 直接影响

- 设置窗口标题栏、文件范围、左侧导航、页面标题和分组标题支持简体中文。
- 大量设置项标题以及 General 页的说明支持简体中文。
- 搜索框、无结果提示、重置/复制链接/编辑 JSON 等操作文本支持简体中文。
- 已打开设置窗口在切换显示语言后立即刷新。

### 间接影响

- 搜索索引同时保留英文与已翻译的中文词条，中文和英文均可用于查找已覆盖设置。
- 元素 ID、设置 JSON 路径、深链接和遥测分类仍使用英文稳定键，不影响已有链接或配置。

### 风险点

- 仍未覆盖的较长说明文本会安全显示英文，后续可按同一入口继续补充。
- 枚举设置的取值标签沿用各枚举的既有显示名称；本次重点覆盖设置窗口框架和设置项文案。

### 兼容性

不改变 `settings.json` 格式、`ui_language` 枚举值或任何现有设置路径，兼容已有用户和项目设置。
