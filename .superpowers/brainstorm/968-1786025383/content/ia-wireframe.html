分区默认与次要入口

A

Tab 分区（上图）

Branches / Remotes / Tags / Shelves 四个 Tab。工具栏「Remotes / Shelf / New Tag」会跳到对应 Tab 或打开创建流。

B

左侧 section 列表

更像设置页导航：左边 section，右边内容。占宽更多，适合大面板。

工具栏拥挤时

1

主按钮 + ⋯ 溢出

常用：Checkout / New Branch / Update Project / Pull / Push；其余进 ⋯（Fetch、Merge、Rebase、Tag、Shelf、Remotes、打开变更面板…）

2

双行工具栏

第一行同步类，第二行分支/合并/标签。信息全可见，垂直空间更贵。
